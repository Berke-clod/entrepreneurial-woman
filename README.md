# entrepreneurial-woman

# 👩‍💼 Women Entrepreneurs Project - E-Commerce and Marketplace Platform A dynamic e-commerce platform similar to Hepsiburada, developed so that women entrepreneurs can bring their products to the digital market, showcase them, and manage their sales processes. 

## 🛠️ Technologies Used 
* **Frontend:** HTML5, CSS3, JavaScript 
* **Backend:** PHP 
* **Database:** MySQL / MariaDB 

## ✨ Key Features 
* Product listing, detailed views, and category management 
* Product and user data flow with dynamic database connection 
* Social impact-focused, user-friendly, and accessible interface 

## ⚙️ Installation and Running 1. Clone or download the project to your computer. 2. Copy the project folder into your XAMPP / WAMP (`htdocs`) directory. 3. Create a new database through phpMyAdmin and import the `.sql` file included in the project. 4. Configure your server settings in the database connection file (e.g., `baglanti.php`).
